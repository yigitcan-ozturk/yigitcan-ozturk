## Engineering principles

- **Evidence before confidence** — outputs should point back to source evidence.
- **Deterministic where possible** — measurable engineering rules belong in code.
- **Explicit uncertainty** — ambiguity becomes review, not fabricated certainty.
- **Fail safely** — unsupported conclusions should remain unsupported.
- **Provenance by design** — requirements, geometry and decisions should remain traceable.
